## things i've built

<br>

### 01 / DevFlow-AI

An intelligent assistant for repository chat, semantic code search, PR reviews, and automated documentation. Because reading undocumented code is painful.

`TypeScript` `GenAI` `RAG`

&rarr; [Code](https://github.com/HariKris-1/devflow-ai)

<br>

### 02 / Document Scanner (VLM)

An OCR-free multimodal pipeline that extracts structured fields directly from raw images using fine-tuned Qwen2-VL with LoRA.

`PyTorch` `Transformers` `Qwen2-VL` `LoRA`

&rarr; [Code](https://github.com/HariKris-1/document-scanner-vlm)

<br>

### 03 / InsightAgent

An autonomous business analyst agent powered by LangChain and OpenAI that actually figures out multi-step business problems over local data instead of just generating chat.

`Python` `LangChain` `OpenAI API` `Agents`

&rarr; [Code](https://github.com/HariKris-1/InsightAgent)

<br>

### 04 / Meridian

An end-to-end streaming ingestion and visualization pipeline. Runs Kafka event streams through FastAPI into Postgres, applying dbt transformations to power a Neo4j graph and Streamlit dashboard.

`Kafka` `dbt` `PostgreSQL` `Neo4j` `FastAPI`

&rarr; [Code](https://github.com/HariKris-1/Meridian)

<br>

### 05 / BusinessInsights-AI

A sales and business intelligence platform that automates insights, executive reporting, and natural language-to-SQL analytics using Generative AI workflows.

`Python` `FastAPI` `OpenAI API` `Plotly Dash`

&rarr; [Code](https://github.com/HariKris-1/BusinessInsights-AI)

<br>

### 06 / ShortLink

A scalable, high-concurrency URL-shortening service featuring token-bucket rate limiting and asynchronous processing.

`AWS` `Redis` `SQS` `Docker` `CI/CD`

&rarr; [Code](https://github.com/HariKris-1/ShortLink)
